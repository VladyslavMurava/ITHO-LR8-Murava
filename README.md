## Як запустити блокнот

1. Відкрити `ІТХО_ЛР7_Мурава_13.ipynb` у Google Colab (File → Open notebook → GitHub → вставити адресу цього репозиторію).
2. Runtime → Change runtime type → GPU T4.
3. Runtime → Run all; при запиті дозволити доступ до Google Drive.

Набір даних CIFAKE завантажується автоматично з Hugging Face.
